Политика использования файлов cookie

1. Общие положения

Настоящая Политика использования файлов cookie (далее — «Политика») действует в отношении официального сайта школы (далее — «Сайт»). Использование Сайта означает согласие Пользователя с обработкой данных, собираемых с помощью файлов cookie, в соответствии с настоящей Политикой.

2. Что такое файлы cookie?

Файлы cookie — это небольшие текстовые файлы, которые сохраняются на устройстве Пользователя (компьютере, планшете, смартфоне) при посещении сайта. Они помогают Сайту запоминать действия и предпочтения Пользователя.

3. Типы используемых файлов cookie

3.1. Строго необходимые (технические)

Эти файлы cookie необходимы для корректной работы Сайта. Они обеспечивают:

  • Авторизацию и безопасность
  • Сохранение настроек сессии
  • Работу основных функций Сайта

Данные файлы cookie не могут быть отключены.

3.2. Аналитические (статистические)

Используются для сбора анонимной статистической информации:

  • Количество посетителей Сайта
  • Страницы, которые они посещают
  • Время, проведенное на Сайте
  • Устройства и браузеры посетителей

Для сбора статистики используется Яндекс.Метрика — сервис веб-аналитики компании «Яндекс».

4. Яндекс.Метрика

4.1. Что это такое?

Яндекс.Метрика — это бесплатный сервис для анализа посещаемости сайтов, предоставляемый компанией «Яндекс».

4.2. Какие данные собираются?

Сервис собирает обезличенные данные:

  • Количество посетителей
  • Географию посещений (город, страна)
  • Источники трафика (поисковые системы, социальные сети)
  • Технические характеристики устройств
  • Поведение на сайте (клики, переходы, время)

4.3. Как используются данные?

Собранные данные помогают:

  • Улучшать удобство Сайта
  • Оптимизировать контент для посетителей
  • Понимать интересы пользователей
  • Принимать решения по развитию Сайта

Все данные собираются в обезличенном виде и не могут быть использованы для идентификации конкретного человека.

5. Управление файлами cookie

5.1. При первом посещении

При первом посещении Сайта Пользователь видит уведомление с возможностью выбора:

  • ✅ «Принять всё» — согласие на использование всех типов файлов cookie, включая аналитические
  • ❌ «Отклонить» — использование только технических файлов cookie, отказ от сбора статистики

5.2. Как изменить решение?

Пользователь может в любой момент:

  1. Очистить файлы cookie в настройках браузера
  2. Настроить браузер на блокировку определенных типов cookie
  3. Переустановить выбор при следующем посещении Сайта

5.3. Инструкция для популярных браузеров:

  • Google Chrome: Настройки → Конфиденциальность и безопасность → Файлы cookie
  • Mozilla Firefox: Настройки → Приватность и защита → Куки
  • Safari: Настройки → Конфиденциальность → Управление данными сайтов
  • Яндекс.Браузер: Настройки → Сайты → Файлы cookie

6. Срок хранения файлов cookie

  • Сессионные cookie: удаляются после закрытия браузера
  • Постоянные cookie: хранятся от 30 дней до 1 года в зависимости от типа

7. Правовые основания

Обработка данных с помощью файлов cookie осуществляется в соответствии с:

  • Федеральным законом № 152-ФЗ «О персональных данных»
  • Политикой конфиденциальности Школы
  • Согласием Пользователя, выраженным через интерактивное уведомление
